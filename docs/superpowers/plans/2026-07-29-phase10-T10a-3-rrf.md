## 范围

1. **RRF 纯函数**: `reciprocal_rank_fusion(ranked_lists, key_fn, k=60) -> (fused_results, FusionStats)`. 接受 N 个已排序的 ranked list (本期 N=2: vector + FTS, 但函数本身支持任意 N 列表), 用 RRF 公式 `score(d) = Σ_i  1/(k + rank_i(d))` 融合, 返回 [(item, fused_score), ...] 按 fused_score 降序, 并并行返回 FusionStats.
2. **`FusionStats` frozen dataclass**: `vector_hits` (仅出现在 vector 列表中的独立 item 数) / `fts_hits` (仅 FTS) / `both_hits` (两列表都有的独立 item 数). T10a-7 直接取用, retriever 层不重复计算.

### 接口签名

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Callable, Sequence, TypeVar

T = TypeVar("T")


@dataclass(frozen=True)
class FusionStats:
    """Hit analytics for a single fusion call.

    Fields are INDEPENDENT unique-item counts:
    - vector_hits: items that appear ONLY in the vector ranked list
    - fts_hits:    items that appear ONLY in the FTS ranked list
    - both_hits:   items that appear in BOTH lists (deduplicated)
    """
    vector_hits: int
    fts_hits: int
    both_hits: int


def reciprocal_rank_fusion(
    ranked_lists: Sequence[Sequence[T]],
    key_fn: Callable[[T], str],
    k: int = 60,
) -> tuple[list[tuple[T, float]], FusionStats]:
    """Pure RRF: fuse N ranked lists by RRF formula.

    Args:
        ranked_lists: Each sublist is already sorted (rank 1 = best).
                      T10a-4 calls with N=2: (vector_hits, fts_hits).
        key_fn:       Extracts deduplication key from each item.
                      T10a-4 will use chunk identity (T10a-5 chunk_id
                      or fallback to doc_hash + source_block_ids[0]).
        k:            RRF dampening constant. parent plan §cross-doc
                      adjud 锁定 k=60 hard-coded; explicit kwarg for
                      testability (test cases use k=1 to verify fusion
                      logic without 60x slowdown).

    Returns:
        (fused_results, stats):
            fused_results = [(item, fused_score), ...] sorted desc by
                            fused_score. Ties broken by insertion order
                            (first-appearance-wins; deterministic).
            stats = FusionStats with hit-set membership analytics.

    Pure (R2): no I/O, no state, no side effects. Replay-deterministic.
    """
```

### RRF 数学

```
score(d) = Σ_{i ∈ ranked_lists}  1 / (k + rank_i(d))
```

- rank_i(d) = d 在第 i 列表中的位置 (1-indexed).
- 不在列表 → 不贡献 score.
- 两列表都出现 → score 是两贡献之和.
- ties: Python dict + insertion-order key walk 保证稳定性; 同分 → 先出现在合并 key 集合中的优先 (dict 行为).

### FusionStats 计算

```
unique_keys = ∪_i keys(ranked_lists[i])
vector_keys = keys(ranked_lists[0])          # 假设第一参数 = vector list (约定)
fts_keys    = keys(ranked_lists[1])          # 假设第二参数 = FTS list    (约定)

vector_hits = |unique_keys ∩ vector_keys| - both_hits
fts_hits    = |unique_keys ∩ fts_keys|    - both_hits
both_hits   = |unique_keys ∩ vector_keys ∩ fts_keys|
```

**约定 (M1 新)**: T10a-4 调用 RRF 时按 (vector_list, fts_list) 顺序传入, FusionStats 字段分配依赖顺序. 这与 retriever 端接入的实际调用语义对齐 (vector 先, fts 后). 文档 + 单测 + 类型注解三重锁定.

**非对称越界**: 若 ranked_lists 长度 ≠ 2, FusionStats 字段值映射约定 (e.g. N=1 只填 vector_hits, 其他填 0) — 由 retriever 端保证调用形态, 单元测试覆盖 N=2 主路径 + N=1 退化路径.
