### 测试 2: 3 工程标识符 BM25-only recall@1 (数据收集)

**结构**: `tests/unit/test_fts_identifier_recall.py`, ≥3 测试:

```python
def test_bm25_recall_at_1_for_A312_TP316(tmp_path):
    """'A312-TP316' (ASME 标准) — 5 文档, BM25-only query 'A312-TP316'."""
    fts = FTSManager(tmp_path / "fts.db")
    try:
        # Write 5 chunks with the identifier; 1 contains it as the *only* content
        for i, ctx in enumerate([
            ("管道规格 A312-TP316", "第3章", "b0"),
            ("管道规格 A312-TP316 标准", "第3章", "b1"),
            ("管道规格", "第3章", "b2"),
            ("A312-TP316", "第4章", "b3"),  # 1-chunk content
            ("test", "第5章", "b4"),
        ]):
            chunk = Chunk(text=ctx[0], scope_path=[ctx[1]],
                          source_block_ids=[ctx[2]], doc_hash=f"d{i}",
                          version=1, page_numbers=[1], numeric_hints=[])
            fts.upsert(FTSManager.generate_chunk_id(f"d{i}", 0), ctx[2], chunk,
                       {"doc_hash": f"d{i}"})
        # BM25-only query
        hits = fts.search("A312-TP316", limit=10)
        recall_1 = 1 if hits and "d3-0000" in {c for c, _ in hits} else 0
        # Log the result for T10c decision data
        print(f"\n[BM25-RECALL-1] A312-TP316 → {recall_1}")
        # Soft assertion: recall_1 may be 0 (CJK + unicode61 limitation)
        # — not blocking, just data
```

3 个工程标识符:
- `A312-TP316` — ASME 牌号 (英文+数字+连字符)
- `GB/T 12459` — 国标 (中文+英文+数字+斜杠)
- `1.6MPa` — 压力值 (数字+点+单位)

每个测试 fixture 写入 5 个 chunk (4 个含有干扰文本 + 1 个"仅标识符"目标), 查询 BM25, 记录 recall@1.

**为什么 fixture 不 hard-assert recall@1 = 1**: CJK + `unicode61 remove_diacritics 2` tokenizer 在 §open 问题已知有 `A312-TP316` 召回不稳的风险. T10a-6 的目标是**收集决策数据**, 不阻塞召回缺陷 (召回缺陷是 T10c 的工作).
